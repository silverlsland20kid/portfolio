# Driving School Landing Page

운전면허 학원 모바일 랜딩페이지 퍼블리싱 프로젝트
떄는 바야흐로,,,, 2025~2026년도 사이에 기능2번 도로2번을 떨어졌던 저는 큰 결심을 가지고 운전면허 등록증을 취득하게 되며
이상태로는 도로에 나가기 어렵다고 판단하여 운전연수 학원을 등록하게 됩니다.
그리고 운전연수 강사님과 방방곳곳을 드라이브하며 운전연수 프로그램에 대한 이야기를 나누게 되었고,
그리하여 강사님과 가볍게 시작한 이야기를 바탕으로 새로운 프로젝트를 시작하게 되는데....
저와 강사님과 원하는 방향대로 운전연수 학원 앱을 만들 수 있을까요?/.....
